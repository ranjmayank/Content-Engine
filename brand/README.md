# Brand kit

`python3 brand/scripts/make_brand.py` (needs `pip install Pillow`) writes a starter kit here from `engine.config.json` → `brand` and `colors`:
avatar, light/dark wordmarks, a 1200×630 Open Graph image, LinkedIn (1584×396) and Facebook (1640×624) covers, and a 1080×1350 quote card (`--quote "your line"`).

Replace any of them with your own designs — keep the file names and the skills will keep pointing at them. Upload them to a Canva brand kit if you use the Canva connector. Fonts in `scripts/fonts/` are SIL Open Font License.
