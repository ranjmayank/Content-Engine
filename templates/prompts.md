# Prompt templates

For when you're using Claude without the skills loaded (a plain chat or another AI tool). Paste `engine.config.json` first, or fill the [brackets]. With the skills loaded, just name the task — the skill does the rest.

---

## 1. Decode post (400–700 words)
```
Write today's decode post for [site]. It must fit one of my pillars: [pillars]. Audience: [audience].
If a query in my analytics report matches, use it as the title.

News item / tool / insight: [headline + link + 2–3 lines of context]

Structure: title = the question this answers (search-phrased) · TL;DR (3 bullets) · what happened (2–3 sentences,
primary link, exact numbers) · what it means for [audience] (2–3 short sections) · one thing to do this week ·
3-question FAQ. Voice: [voice]. Never: [banned phrases]. Never invent numbers.
Then: a 40-second Reel script (ON-SCREEN TEXT | VOICEOVER) and one quote-card line.
```

## 2. Deep post (2,000–3,000 words)
```
Write a cornerstone post for [site].
Topic: [...] · Pillar: [...] · My site data: [query, impressions, position, window]
My proof/experience: [1–3 anonymized lines from my work]
Include: the problem, why now, the impact, a practical framework, examples, metrics, steps, CTA ([end CTA]).
TL;DR after the intro, 7–10 FAQs, meta title + description, 3 internal-link suggestions.
Every stat needs a source link — flag any you can't source instead of inventing one. Show me the outline first.
```

## 3. LinkedIn post
```
Today's LinkedIn post. Pillar: [...] · Idea: [...] · Source: [link + fact] · My line: [...]
Hook under 15 words (not starting with "I"), rehook before the fold, short paragraphs, one takeaway,
a specific engagement question, 3–5 hashtags. Link goes in the first comment. Never name: [confidential].
```

## 4. Carousel (8 slides)
```
Turn this into an 8-slide carousel: [post or section]
1 hook (≤10 words) · 2 problem · 3 hidden cost · 4 reframe · 5 framework (3–4 steps, verbs first) · 6 proof ·
7 this-week action · 8 CTA ([site] · [handle]). Max 20 words a slide; source footer on any slide with a number.
Then the Instagram caption + 5 hashtags.
```

## 5. News Reel (40 seconds, faceless)
```
News item: [paste]. Run the 3-filter (in my pillars and my audience cares? / do I have an angle? / one sharp line?).
If it fails, say why in one line and stop. Otherwise: ON-SCREEN TEXT (≤8 words/card) | VOICEOVER —
hook 0–2s, agitate, 3 points, payoff, CTA. Then caption + 5 hashtags.
```

## 6. Weekly newsletter
```
Turn this week's posts into my letter: [titles + key points]
Sections: the change of the week · one practical move · one workflow · one number from my own site.
300–500 words, personal letter voice, one link per post, subject line under 50 characters = the sharpest claim.
```

## 7. Site check
```
Read analytics/reports/latest.md and seo-audit/reports/latest.md and give me this week's 5 actions
(update / rewrite / write / merge / fix), post ideas from my data, and what AI assistants sent.
Every number with its date window. No estimates.
```
